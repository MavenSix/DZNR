This folder holds DZNR-specific skills — typically renamed versions of skills from other sources to avoid name collisions documented in `governance/DECISIONS.md`.

## Adding a curated skill

Only happens through the Evolution Protocol (`governance/EVOLUTION.md`).

1. Propose
2. Get approval
3. Create the curated SKILL.md here with the disambiguated name
4. Update routing docs to reference the new name
5. Re-run stress tests
